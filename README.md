# あさ・よるの やることリスト(iPad版 / GitHub Pages で公開)

4歳のお子さん向けの、朝と夜の「やることリスト」です。
GitHub Pages に置いて、iPad の Safari から開いて使います。
一度開けば iPad の中に保存されるので、**次からは電波がなくても開けます**。

## 公開されるもの・されないもの

- 公開されるのは**アプリのファイル(このフォルダの中身)だけ**です。アドレスを知っていれば誰でも開けます
- **花丸の記録と動画は iPad の中だけ**に保存され、GitHub やインターネットには送られません
- `my_pictures` に入れた画像は公開されます。家族の写真などは入れないでください

## GitHub Pages に置く手順(パソコンで行います)

### 1. リポジトリを作る

1. [github.com](https://github.com) にログインします
2. 右上の「＋」→「New repository」を押します
3. Repository name に `yarukoto` と入れます(好きな名前でかまいません)
4. **Public** を選びます(無料プランでは Public でないと GitHub Pages が使えません)
5. 「Create repository」を押します

### 2. ファイルをアップロードする

1. できたページの「uploading an existing file」のリンクを押します
2. 展開した `yarukoto_pages` フォルダを開き、**中身をすべて選んで**(Ctrl + A)、ブラウザの画面にドラッグします
   - フォルダごとではなく、中のファイルと `my_pictures` フォルダをドラッグします
   - `index.html` がリポジトリのいちばん上に来るのが正しい状態です
3. 下の「Commit changes」を押します

### 3. 公開の設定をする

1. リポジトリの上のメニューから「Settings」を押します
2. 左のメニューから「Pages」を押します
3. 「Build and deployment」の Source を「Deploy from a branch」にします
4. Branch を「main」、フォルダを「/ (root)」にして「Save」を押します
5. 数分待ってページを読み込み直すと、上に公開アドレスが表示されます

アドレスは `https://(ユーザー名).github.io/yarukoto/` の形になります。

## iPad での準備

1. Safari で公開アドレスを開きます
2. 共有ボタン(□に↑)→ **「ホーム画面に追加」**
3. ホーム画面にできた「やること」のアイコンから開きます(全画面になります)
4. **Wi-Fi につないだ状態で、一度アプリを閉じてもう一度開きます**(これで iPad への保存が確実になります)

**必ずホーム画面のアイコンから使ってください。** Safari で開いたものとは保存場所が別で、
Safari のままだと、しばらく使わないと記録や動画が消えることがあります。

### 動画を入れる

1. 画面の**左下のすみを2秒ながおし**します
2. かけざんの答えをタッチすると「おとなメニュー」が開きます
3. 「動画を追加する」から、写真アプリやファイルアプリの動画を選びます
4. 「名前を変える」で、画面に出す名前をひらがなにできます

4本以上あるときは、毎回ランダムに3本が出ます。
長い動画をたくさん入れると iPad の容量を使うので、数分程度の動画がおすすめです。

### ためす

おとなメニューの「朝をためす」「夜をためす」「朝＋注意をためす」で、時間に関係なく動かせます。
テスト中の花丸は保存されません。終わったら「テストをやめる」を押してください。

### こえ(読み上げ)

iPad に最初から入っている読み上げ機能で、次の場面で声が出ます(インターネットとは通信しません)。

| 場面 | 言うこと(例) |
|---|---|
| 朝・夜のはじまり | 「おはよう! あさの やること、はじめよう!」 |
| やることをタッチ | 「ごはん、できたね!」/ ぜんぶ終わると「ぜんぶ できたね! すごい! もんだいに ちょうせんしよう!」 |
| もんだいを出したとき | 「4 たす 5 は、いくつ?」のあと、こたえを上から順に読む(読んでいるボタンが光ります) |
| まちがえたとき | 「ちがうよ。もういちど、かんがえてみよう」 |
| せいかいしたとき | 「せいかい! 4 たす 5 は、9 だよ!」「せいかい! ここは、ちばけん だよ!」など |
| 花丸 | 「はなまる! よくできました!」 |
| 動画えらび・おわり | 「どれを みる?」/「よくできました! いってらっしゃい!」 |
| 注意(7時半) | 「いそごう! まだ ひとつも おわってないよ」(ピッピッの合間に、ときどき声で) |

- もんだいの画面の左上の**スピーカーのボタン**を押すと、もう一度読みます
- おとなメニューの「こえ(読み上げ)」でオン/オフと、こえのテストができます
- はやさ・声の高さ・こたえも読むかどうかは `config.js` の `voice` で変えられます
- **アプリを開いてから一度も画面をタッチしていないと、声は出ません**(iPad の決まり)。開きっぱなしで使っていれば、前の日にタッチしているので大丈夫です
- 声がこもって聞こえるときは、iPad の 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語 で、「Kyoko(拡張)」などの声をダウンロードすると聞きやすくなります
- 消音モードやマナーモードだと声が出ないことがあります。音量も確認してください

### もんだいだけモード

やることリストなしで、もんだいだけを次々に出すモードです。時間外でも使えます。

1. おとなメニューを開きます(左下のすみを2秒ながおし)
2. 「もんだいだけモード」の「ぜんぶ」「たしざんだけ」「にほんちずだけ」「これはなに？だけ」のどれかを押します
3. やめるときは、おとなメニューの「やめる」を押します

- せいかいすると右上の★が1つふえて、次のもんだいが出ます
- 花丸と動画はありません(カレンダーには記録されません)
- 朝・夜の時間が始まると自動で終わり、やることリストに切り替わります
- アプリを開き直すと、ふつうのモードにもどります

### iPad 側の設定

- **自動ロックを「なし」**(設定 → 画面表示と明るさ → 自動ロック)
- **アクセスガイド**(設定 → アクセシビリティ → アクセスガイド)をオンにして、アプリを開いた状態でトップボタン(またはホームボタン)を3回押すと、子どもが他のアプリに移動できなくなります
- **音量**を上げ、消音になっていないか確認します
- iPad は**よこ向き**で使います

## 設定を変える(config.js)

| 項目 | 初期値 | 説明 |
|---|---|---|
| `weekdays_only` | `false` | `true`:月〜金だけ / `false`:毎日 |
| `morning` | 06:30〜08:10、注意 07:30 | 朝の時間と注意の時刻 |
| `evening` | 18:00〜21:00、注意なし | 夜の時間と注意の時刻 |
| `warn_condition` | `'none_done'` | `'none_done'`:1つも終わっていないとき / `'any_left'`:1つでも残っているとき |
| `videos_per_session` | `1` | 朝・夜それぞれで見られる動画の本数(`0` で無制限) |
| `quiz_types` | 3種類すべて | 出す問題の種類 |
| `map_prefectures` | `[]` | 地図問題に出す都道府県(空なら全部) |
| `voice` | オン、はやさ 0.9 | 読み上げのオン/オフ・はやさ・声の高さ・こたえも読むか |
| `my_pictures` | `[]` | 「これは なに?」に追加する絵のファイル名 |

### 変え方(GitHub の画面でできます)

1. リポジトリで `config.js` を押します
2. 右上の鉛筆マークを押して書きかえます
3. 「Commit changes」を押します
4. 数分待ってから、iPad を Wi-Fi につないだ状態で**アプリを2回開き直します**
   (1回目で新しい版を取りこみ、2回目から使われます)

やることの項目を変えたいときは `app.js` の先頭の `TASKS` を同じ方法で書きかえます。

## ファイルの中身

| ファイル | 内容 |

| `index.html` `style.css` `app.js` | 画面 |

## 動作の細かい決まり

- 時間外は、暗い画面に時計だけ出ます(初期設定では土日も動きます)。時間になると自動でリストに切り替わります
- 画面の点灯は親が行います。注意(7時半)の表示は、画面がついてアプリが開いているときだけ出ます
- 注意の音は、その回に一度も画面をタッチしていないと鳴りません(iPad の決まり)。画面の点滅は出ます
- 動画は、最後まで見るか20秒以上見たときに「1本見た」と数えます
- `weekdays_only` を `true`(平日だけ)にした場合、祝日は判定しません(平日として動きます)
- ホーム画面のアイコンを削除すると、記録と動画も消えます

## 動作確認について

パソコン上の Chrome(iPad よこ向きと同じ大きさ)で、おとなメニュー → 動画の追加・削除 → リスト → もんだい → 花丸
→ 動画再生 → 記録の保存と復元、配信を止めた状態(オフライン)での起動、各場面で読み上げる文と順番まで確認しています
(実際の声は、パソコンの確認環境に日本語の声がないため聞いていません)。

**iPad の実機では未確認**です。最初に次の点を確認してください。

- 機内モードにしてもアプリが開けるか
- 声が出るか(おとなメニューの「こえのテスト」)
- 取り込んだ動画が再生できるか(再生が始まらないときは、画面を一度タッチしてください)
- 動画えらびの表紙の絵が出ない場合があります(名前と再生マークは出ます)
